# Supplementary Material for Moore-Type QC LDPC Codes

This repository contains the supplementary calculations for the manuscript

**On the Minimum Distance of High-rate Moore-Type Quasi-Cyclic LDPC Codes.**

The supplementary material provides the detailed algebraic derivations
for Cases II--VII in the characterization of weight-8 codewords.

The six cases are:

- Case II: subcase 1-2-1
- Case III: subcase 1-2-2
- Case IV: subcase 2-1-2
- Case V: subcase 2-1-7
- Case VI: subcase 2-3-5
- Case VII: subcase 2-4-3

The source file is

`Supplementary_Material_Moore_QC_LDPC.tex`

and the compiled document is

`Supplementary_Material_Moore_QC_LDPC.pdf`.
